  HOW TO INSTALL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Extract the ZIP file to a folder on your computer.
2. Open the extracted folder.
3. Double-click "VoltrimFlipCraftPro-Setup-1.0.0.exe".
4. Follow the on-screen installation steps.
5. Click Finish — Voltrim FlipCraft Pro launches automatically.

  IMPORTANT — WINDOWS SECURITY MESSAGE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

When you run the installer for the first time, Windows may display
a security notification such as:

  "Windows protected your PC"

This is a standard Windows SmartScreen check that appears for
independently published software distributed outside large app
stores. It does NOT mean the software is harmful.

Voltrim FlipCraft Pro:

  ✔  Does not collect any personal information
  ✔  Does not connect to the internet during normal use
  ✔  Only downloads required components on first use
     (Poppler ~25 MB on first launch, viewer libraries
      ~4 MB on first flipbook creation — both one-time only)
  ✔  Does not contain viruses, malware, or harmful code
  ✔  All your documents and flipbooks stay on your computer

If the Windows security message appears:

  1. Click "More info"
  2. Click "Run anyway"

Installation will then proceed normally.

  FIRST LAUNCH
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

On first launch, Voltrim FlipCraft Pro will automatically download
the Poppler PDF rendering engine (~25 MB) from GitHub.

  • This is a one-time download only.
  • An internet connection is required for this step only.
  • After the initial setup, the application works fully offline.
  • The download takes approximately 1–2 minutes depending on
    your connection speed.

On your first flipbook creation, a small additional download
of viewer display libraries (~4 MB) also occurs once.
After that, all flipbook creation works completely offline.

  ABOUT YOUR FLIPBOOK OUTPUT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Every flipbook you create with Voltrim FlipCraft Pro produces
two files:

  [Title].exe  —  The viewer application (contains the decryption key)
  [Title].dat  —  The encrypted flipbook content

Both files must always stay in the same folder.
To open the flipbook, simply double-click the .exe file.

The .dat file is encrypted with a unique key — its content is
completely unreadable without the matching .exe. Your source
documents and images cannot be extracted from the output.

NOTE: When recipients open your flipbook .exe for the first time,
Windows may show the same SmartScreen message described above.
A ready-made note for your recipients is included separately
in this package as "READ_ME_FIRST_Flipbook-Recipients.txt".
