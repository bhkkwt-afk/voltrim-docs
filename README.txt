WHAT IS VOLTRIM FLIPCRAFT?

Voltrim FlipCraft converts PDFs, image collections, and Word documents into
beautiful interactive flipbooks with realistic 3D page-turn animations, sounds,
a progress bar, zoom controls, and fullscreen mode. The output is a protected
Windows executable (.exe) that your audience can open instantly — no browser,
no internet, no installation required on their end.

EDITIONS

  Basic  — Creates an interactive flipbook viewer executable from PDF files.
           Supports PDF creation mode with adjustable quality settings.

  Pro    — All Basic features plus:
           • Image Album mode (from JPG/PNG image folders)
           • Word Document mode (.docx/.doc via Microsoft Word or LibreOffice)
           • Multi-Document Merge mode (combine PDFs + Word docs)
           • Built-in content encryption — each flipbook is unique and protected

CONTENT PROTECTION (Pro edition)

  Every flipbook created by the Pro edition produces two files:

    [Title].exe  — The viewer application (contains the encryption key)
    [Title].dat  — The encrypted flipbook content

  The .dat file is encrypted with a unique per-flipbook key and is unreadable
  without its matching .exe. Deliver both files together to your customers.

SYSTEM REQUIREMENTS

  Operating System : Windows 10 or Windows 11 (64-bit)
  RAM              : 2 GB minimum, 4 GB recommended
  Disk Space       : 200 MB
  Internet         : Required on first run only (to download Poppler, ~25 MB)

  Pro edition also requires .NET Framework 4.5 or later (pre-installed on
  all modern Windows PCs).

  Word Document mode requires Microsoft Word or LibreOffice (free download
  from libreoffice.org) — Pro edition only.

QUICK START

  1. Launch Voltrim FlipCraft (Basic or Pro)
  2. On first launch, the Poppler PDF engine downloads automatically (~25 MB)
  3. Select your creation mode (PDF, Image Album, Word Document, or Merge)
  4. Choose your source file or folder
  5. Choose image quality (Standard 150 DPI recommended for most documents)
  6. Click Create Flipbook
  7. When complete, click Open Folder to find your output files
  8. Double-click the flipbook .exe to launch it

KEYBOARD SHORTCUTS (inside the flipbook viewer)

  Arrow Right / Arrow Left  — Next / Previous page
  F                         — Toggle fullscreen
  M                         — Toggle sound mute
  + / -                     — Zoom in / out

CHECK UPDATES

  The Check Updates button downloads and installs the latest version of
  Poppler, the PDF rendering engine. Internet connection required.

UNINSTALLING

  Use Windows Settings → Apps → Voltrim FlipCraft → Uninstall.
  Your generated flipbooks are NOT deleted during uninstallation.
