  📖  WHAT IS A FLIPBOOK?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A flipbook is an interactive digital document that opens like a real
book — pages turn with a smooth 3D animation, there is a progress
bar, keyboard navigation, and a fullscreen mode.

The output is a professional Windows viewer (.exe) that anyone can
simply double-click to open — no browser, no internet, and no
installation required.

  🔐  CONTENT PROTECTION — HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Unlike other flipbook tools that deliver a readable HTML file,
FlipCraft Pro protects your content using encryption.

Every flipbook you create produces two files:

  ⚙️  [Title].exe  —  The viewer application
                       Contains the unique decryption key.

  🔑  [Title].dat  —  Your encrypted flipbook content
                       Completely unreadable without the .exe.

How the protection works:

  🔸  Unique encryption key per flipbook — each document gets its
      own key, so one key cannot unlock another.

  🔸  No extractable HTML or images — viewers cannot open,
      copy, or repurpose your source content.

  🔸  Temporary access only — content is decrypted into a hidden
      system folder at runtime and deleted when the viewer closes.

  🔸  Native Windows viewer — just double-click the .exe.
      No browser, no plugins, no installation needed.
